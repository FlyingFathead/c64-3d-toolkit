# Don’t Lose Your Marbles — early concept tryout

Archived first beta on the v0.6.5 toolkit baseline. These are the original
cartridges, baked Blender scene and reports from that experiment, preserved
byte-for-byte. This 750-sample scene loops in about 72.8 seconds; the intro runs
once. It predates the centred collision pours, table fracture, finite ending,
greetings joke and ghost-in-BASIC epilogue.

The long running time, wide pours and reported disappearing-marble symptom
made this an exploratory build. Keep it for comparison, not as the current demo.
The [current early beta](../../../cart_marbles/README.md) ships with v0.6.6.

`README-original.md` and the original reports describe this archived build.
`archive-provenance.json` records checksums and the source package. The baked
scene can be opened directly in Blender. Reproducing the original cartridge
requires the original beta’s tools/options, rather than today’s finite defaults.
