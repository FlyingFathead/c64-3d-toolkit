# Archived demo cartridges

These are the preserved, superseded mixed-method menu cartridges and their
original reports. Their bytes are unchanged. Paths inside historical manifests
and reports describe the original build locations.

Use the uniform V3/V4 comparison carts in `../../cart_demos/` for current A/B
testing. Run `python tools/archive_old_carts.py` after overlaying an update ZIP
to archive the known old filenames in your checkout; local edits are preserved.
